# Afro Genie Backend

Backend service for Afro Genie.

## Tech Stack
- Node.js, TypeScript, Express, Prisma, PostgreSQL
- Redis (BullMQ), Typesense

## Getting Started
1. npm ci
2. cp .env.example .env
3. npm run prisma:generate && npx prisma migrate deploy
4. npm run dev

## Scripts
- npm run build
- npm start
- npm test
